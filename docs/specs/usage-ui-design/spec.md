# 사용량 화면 디자인 개선

기능: token-usage(기준 spec docs/features/token-usage.md)
이슈: GitHub #2

## 무엇을, 왜

사용량 조회 화면(`src/Biz.Bizadm.ClaudeTokenUsage.Client`)은 기능은 동작하지만 읽기 어렵다.

- 차트 계열 색이 회색 명도 단계뿐이라 계열이 구분되지 않는다(output 막대가 사실상 보이지 않음).
- 비용(USD) 선이 토큰 막대 위에 보조 축으로 겹쳐 그려지고, 곡선 보간 때문에 사용량이 없는 구간 사이에도 값이 있는 것처럼 보인다.
- 축 숫자가 160000처럼 줄이지 않은 채 나오고, 비용 축에 단위 표기가 없다.
- 구간을 좁혀 보거나 계열을 숨기는 상호작용이 없다.
- 요약이 토큰·비용 총합 두 숫자뿐이라 계열별 비중을 알 수 없다.
- 페이지 배경과 카드가 같은 흰색이라 영역이 구분되지 않는다.
- 언제 조회한 값인지 알 수 없고, 기간의 끝이 화면을 연 순간에 고정되어 열어 둔 채로는 새 사용량이 보이지 않는다. 다크 모드를 고를 수 없다.

차트를 Apache ECharts로 바꾸고(D004), 계열 색·비용 차트·숫자 표기·요약·헤더·레이아웃을 다듬고, 열어 둔 화면이 10초마다 자동 갱신되게 한다(D005, D006). 필터 영역(단위·기간·나눠 볼 기준·체크박스 목록)의 모양은 이번 범위에 넣지 않는다(D003). 조회 API와 서버는 바꾸지 않는다.

## 완료 조건

- C1. 토큰 차트는 구간별로 계열을 쌓은 막대로 그린다. 계열 8개까지는 서로 다른 색상(색상이 다른 8색 팔레트, 라이트·다크 모드 각각)을 쓰고, 9번째부터는 팔레트를 처음부터 다시 쓴다. 같은 계열은 차트·범례·요약에서 같은 색이다. 나눠 볼 기준이나 사용자·모델·토큰 종류 필터를 바꾸면 색을 응답 순서대로 다시 매긴다. 그 밖의 갱신(자동 갱신·새로고침·기간 변경)에서는 계열 이름별 색을 유지하고, 새로 나타난 계열은 지금 화면의 계열이 쓰지 않는 색 가운데 가장 앞 번호를 받는다(모두 쓰고 있으면 처음부터). 색은 지금 응답에 있는 계열(범례로 숨긴 계열 포함)만 가지며, 응답에서 빠진 계열은 색을 잃고, 다시 나타나면 색은 새로 나타난 계열처럼 받는다. 범례 숨김은 C4대로 계열 이름에 묶여 그대로 유지된다. 여기서 "지금 화면의 계열"은 지금 응답의 계열 전부다.
- C2. 비용(USD)은 토큰 차트 아래 별도 막대 차트로 그리며, 두 차트는 같은 구간 X축을 쓴다. 조회 결과의 비용이 모두 null이면(토큰 종류로 거른 경우) 비용 차트를 그리지 않는다.
- C3. 두 차트에서 보는 구간 범위를 좁히고 넓힐 수 있고(확대·이동), 한 차트에서 범위를 바꾸면 다른 차트도 같은 범위로 바뀐다. 한 차트에서 구간에 마우스를 올리면 두 차트 모두 그 구간을 가리킨다.
- C4. 토큰 차트 범례 항목을 누르면 그 계열이 차트에서 숨겨지고, 다시 누르면 보인다. 숨김은 계열 이름에 묶인다.
- C5. 토큰 축 눈금은 K·M·B로 줄여 쓰고(예: 160000 → 160K), 비용 축 눈금은 $를 붙인다. 툴팁에는 구간 라벨(KST), 계열별 토큰(천 단위 구분), 구간 토큰 합계, 비용이 있으면 비용($, 소수 넷째 자리)을 보인다. 툴팁의 구간 토큰 합계는 범례로 숨기지 않은 계열만 더한다.
- C6. 요약에 토큰 총합·비용 총합과 함께 계열별 토큰 합계와 고른 기간 토큰 총합 대비 비율(%)을 계열 색과 함께 보인다. 요약은 범례 숨김과 상관없이 고른 기간 전체 값이다. 고른 기간 토큰 총합이 0이면 비율 자리에 "—"를 보인다. 토큰 종류로 거르면 비용을 볼 수 없다는 안내는 지금처럼 보인다.
- C7. 헤더에 마지막으로 성공한 조회 시각(KST)과 새로고침 버튼이 있다. 조회가 실패하면 시각은 그대로 두고 오류를 보인다. 새로고침을 누르면 실시간(C11)이 켜져 있으면 C11과 같이 기간을 지금 기준으로 옮겨 조회하고, 꺼져 있으면 고른 기간 그대로 다시 조회한다. 조회 중에는 조회 중임을 표시한다.
- C8. 헤더의 다크 모드 토글로 라이트·다크를 바꿀 수 있고, 차트도 함께 바뀐다. 고른 값은 브라우저에 저장되어 다시 열어도 유지되며, 고른 적이 없으면 운영체제 설정을 따른다.
- C9. 폭 375px 화면에서 가로 스크롤 없이 필터·요약·차트가 보인다.
- C10. 기존 화면 요구(token-usage R8: 단위·기간 선택, 사용자·모델·토큰 종류 필터, 나눠 볼 기준, 보관 기간 안에서만 기간 선택, 토큰 종류 필터 시 비용 안내)는 그대로 동작하고, 클라이언트 테스트·린트·빌드가 통과한다.
- C11. 헤더에 '실시간' 토글이 있고 처음 열 때 켜져 있다. 켜져 있으면 기간을 지금 기준으로 옮겨 다시 조회한다: 끝은 지금이 속한 분의 다음 분 경계, 시작은 끝에서 옮기기 전 기간 길이만큼 앞(보관 하한보다 이르면 하한)이다. 보이는 탭에서는 10초마다 갱신하고, 탭이 숨겨져도 갱신을 멈추지 않는다(브라우저가 숨은 탭 타이머를 늦추면 간격이 길어질 수 있다). 시작이나 끝을 직접 고르면 토글이 꺼지고, 꺼져 있으면 자동 갱신을 하지 않는다. 다시 켜면 곧바로 기간을 지금 기준으로 옮겨(길이는 그때의 기간 길이) 한 번 조회한다. 자동 갱신 중에도 범례로 숨긴 계열은 유지되고, 확대 범위는 전체 기간 대비 같은 비율(예: 오른쪽 20%)로 유지되어 오른쪽 끝을 보고 있었으면 최신 구간을 따라간다. 확대하지 않았으면 전체 기간을 본다.
- C12. 페이지 배경은 카드 배경과 다른 옅은 색이고(라이트·다크 각각), 헤더·필터·요약·차트 사이 간격이 같으며, 카드의 테두리·모서리가 같다.
